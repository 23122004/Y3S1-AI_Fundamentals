## 🎯 Course Objectives
The primary goal of this course is to master the building blocks of intelligent systems, including:
* **Problem Modeling:** Representing real-world challenges as state-space search or constraint satisfaction problems.
* **Algorithmic Logic:** Implementing rigorous search and inference engines.
* **Optimization:** Leveraging randomness and heuristics to solve non-linear, high-dimensional problems.

---

## 🚀 Projects Overview

### 1. Search Algorithms
* **Description:** Implementation of fundamental agents that navigate state spaces to find optimal paths.
* **Core Algorithms:** * Uninformed Search: **DFS**, **BFS**.
    * Informed Search: **A* Search** with custom heuristic functions.
    * Adversarial Search: **Minimax** and Alpha-Beta Pruning.

### 2. Hashiwokakero (Bridges) Solver
* **Description:** An automated solver for the Japanese logic puzzle "Hashiwokakero," modeled as a **Constraint Satisfaction Problem (CSP)**.
* **Core Algorithms:** * **AC-3 Algorithm** for constraint propagation.
    * Backtracking Search with Forward Checking to ensure all islands are connected according to bridge constraints.

### 3. Stochastic Optimization
* **Description:** Applying metaheuristic approaches to find global optima in complex search spaces where traditional gradient-based methods are inapplicable.
* **Core Algorithms:** * **Hill Climbing** and **Simulated Annealing (SA)**.
    * Advanced studies in **Natural Evolution Strategies (NES)** and **Cuckoo Search (CS)**.
    * Focus on numerical stability and convergence analysis in high-dimensional spaces.
